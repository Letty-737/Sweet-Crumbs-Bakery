<h1>Project Overview</h1>

Sweet Crumbs Bakery is a small bakery business that provides cakes, cupcakes and pastries to customers. The purpose of this project is to develop a functional, informative and visually appealing website for the bakery.

The website will provide customers with information about the bakery, its products, enquiry options and contact details. The website is designed to be easy to navigate and accessible to users.

<h1>Project Goals</h1>

The main goals of the Sweet Crumbs Bakery website are:

* To provide information about the bakery.
* To display the bakery's products.
* To make it easy for customers to submit enquiries.
* To provide contact and location information.
* To create a simple and user-friendly website.
* To demonstrate the use of standards-compliant HTML.

<h1>Key Features</h1>

The website will contain five main pages:

1. Home
2. About Us
3. Products
4. Enquiry
5. Contact

The website will include:

* A navigation menu.
* Bakery images.
* Information about the bakery.
* Product information.
* An enquiry form.
* Contact information.

# 1. Project Overview

Sweet Crumbs Bakery is a bakery website developed to showcase a bakery business, its products and services. The website provides customers with information about the bakery, its menu, special offers, product gallery and contact details.

The purpose of this project is to develop a functional, informative and visually appealing website that allows customers to explore bakery products and make enquiries.

The website was created using Lovable, which was used to design, develop and publish the website.

The main goals of the Sweet Crumbs Bakery website are:

- To provide a gallery of bakery products.

# 7. Project Development Details

The Sweet Crumbs Bakery website was developed using Lovable.

The development process involved planning the website layout, organising its pages, adding content, selecting suitable images and creating features to improve the customer experience.

The Home page introduces the bakery, while the About page provides information about its story and values.

The Menu page displays products and prices, and the Specials page highlights selected promotions.

The Gallery page allows customers to view bakery products through photographs. The Enquiry and Contact pages provide ways for customers to communicate with the bakery.

The Shopping Bag section allows customers to review products they have selected.

The website was designed with user experience in mind, ensuring that visitors can navigate between pages and access important information easily.

# 10. Testing and Limitations

The website was published online and can be accessed through the live website link.

The following areas should be tested to ensure that the website works correctly:

- Navigation links between pages.
- Menu search and category filters.
- Add to Bag functionality.
- Shopping bag calculations.
- Enquiry and contact form submissions.
- Newsletter sign-up.
- Map and location links.
- Mobile and desktop layouts.
- Buttons and interactive elements.

## Limitations

- Online payments are not currently available.
- Some business details, product prices and testimonials are demonstration content.
- The forms and newsletter feature should be tested to confirm that submissions are processed correctly.
- Product availability and pricing should be verified before the website is used by a real business.
- A shopping bag interface does not automatically mean that a complete online ordering system is connected.
